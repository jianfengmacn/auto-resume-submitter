# 常见招聘站点 JD 抽取要点

收集岗位时，用 WebFetch 或浏览器打开链接，目标是抽出下面 6 个字段，存成 `jobs/job_<n>.md`：

```
公司：
岗位：
薪资：
地点：
职责：
要求：（证书/技能/年限/语言）
链接：
```

## Boss 直聘
- 岗位详情页含薪资（如“15-25K·13薪”）、地点、经验要求。
- 注意：频繁访问可能触发验证；抓取后本地留存，不要重复刷。
- JD 正文里“职位描述”和“任职要求”通常分行，便于切分。

## 猎聘 / 智联招聘 / 拉勾
- 多为标准 JD 页，WebFetch 基本能拿正文。
- 薪资常写区间；年限写“5-10年”这类，初筛时与 `years_exp` 比对。

## LinkedIn / Indeed（外企/远程）
- 英文 JD，抽取同上；`required_skills` 可加英文关键词（Excel, SAP, GAAP, FP&A）。
- 远程岗注意标注“远程/Remote”，匹配 `locations` 里的“远程”。

## 通用注意
- **一次多抓**：把多个链接/多条粘贴文本批量存盘，再统一初筛，摊薄成本。
- **隐私**：不要把简历正文写进对外分享的内容；JD 链接可留存用于复盘。
- **限流**：同一站点短时间内不要高频请求，避免被封。

## 各平台填写 / 投递要点（自动发简历时用）

发送阶段用浏览器自动填表，**提交前必须截图给用户核对 + 等用户说“投”**。下面是从易到难的大致填法：

### Boss 直聘
- 多数岗位点「立即沟通 / 投简历」后是和 HR 聊天窗口，简历作为附件发送；少量有「在线简历」表单。
- 自动动作：打开链接 → 点沟通 → 上传/发送简历文件 →（可选）发一句自我介绍。
- 注意：Boss 偏“聊天式”，没有传统提交按钮，确认点在于“是否发送简历给这位 HR”。

### 猎聘 / 智联招聘 / 拉勾
- 多有标准「申请职位」表单：姓名、手机、邮箱、上传简历（docx/pdf）、有时贴求职信。
- 自动动作：填基本信息 → 上传 `resume_file` → 贴 `cover_file` 内容 → 停，**等确认** → 点「提交/申请」。
- 注意：同一个岗不要反复投；部分站投递后不可改，确认前务必核对岗位与简历版本。

### LinkedIn / Indeed（外企 / 远程）
- 「Easy Apply」多为几步表单：联系信息、简历上传、是否愿意远程、签证/薪资期望。
- 自动动作：逐步填 → 上传 → 停，**等确认** → 提交。
- 注意：英文表单字段多，先用截图确认再填，避免误填薪资期望导致被筛。

### 通用填写铁律
- **先截图核对**：公司、岗位、薪资、地点无误再填。
- **简历版本对齐**：队列里写的 `resume_file` 就是这次要传的，别传错。
- **提交前停**：永远在最后一步按钮前停下来等用户确认。
- **守限流**：同平台相邻两次投递间隔数分钟，不短时间高频。
